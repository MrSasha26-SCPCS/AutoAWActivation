# NewAWActivation
SCP: CS plugin

Добавляет ивент: при закрытии ЛЗС по команде совета О5 активируется детонация Альфа боеголовки. Если она выключена, то каждые 2 минуты она будет пытаться активироваться, пока не активируется и не взорвётся.

Полезно, когда карты на подрыв нет, а лёгкая зона уже закрыта.
